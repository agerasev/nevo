# Selected history

Keep only concise conclusions worth preserving: major experiment ideas, main
results, and consequential reasoning. Earlier implementation details and routine
checks are available through Git history.

- [First evolving ecosystem, July 2016](2016-07-26-ecosystem.md): inherited
  food-seeking behavior and the limits of evidence from population survival.
- [Runnable Rust baseline, November 2026](2026-11-04-rust-baseline.md): a repeatable
  ecosystem, with adaptation still unmeasured.
- [First million-tick run, November 2026](2026-11-05-long-run.md): near
  self-sufficiency and food-production saturation in one seed; controlled
  evolutionary comparisons remain open.
- [Movement costs, November 2026](2026-11-05-movement-costs.md): one matched
  300,000-tick pair showed fewer abrupt turns with energy-proportional cost,
  alongside larger population and much slower reproductive turnover.
- [Evolved RNNs versus a gradient follower, November 2026](2026-11-05-gradient-comparison.md):
  similar food collection and population across 32 matched worlds without
  immigration; RNNs showed lower turnover.
- [Controllers after 8.85 million ticks with costly movement](2026-11-05-costly-movement-models.md):
  slower, food-dependent gradient following; rare reproduction and occasional
  immigration persisted.
